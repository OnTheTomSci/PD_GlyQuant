# PD_GlyQuant
Proteome Discover glyco-proteomics exploratory data analysis 

Purpose: Exploratory analysis pipeline for glyco-proteomics data (Proteome Discoverer outputs), focusing on glycan composition, modification statistics (fucosylation/sialylation), and comparative group analyses with publication-ready plots and summary tables.
